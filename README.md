# rancher-sandbox/lima

This repository mirrors [lima-vm/lima](https://github.com/lima-vm/lima) for Rancher Desktop. Its `master` branch and release tags are unmodified copies of upstream's, and Rancher Desktop builds Lima from them through [rancher-sandbox/rancher-desktop-lima](https://github.com/rancher-sandbox/rancher-desktop-lima).

This default branch holds only this README and `.github/OWNERS`, which names the team that owns the repository. Please report Lima bugs and send changes to [lima-vm/lima](https://github.com/lima-vm/lima).
